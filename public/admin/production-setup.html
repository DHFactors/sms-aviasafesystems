Category D: Data Purging & Tenant Deletion

Unified purge of ALL demo data or delete entire tenants.

Step 8

Purge All Demo Data

Delete ALL demo data from BOTH Supabase AND Firestore — Postgres rows (is_demo = true): hazards, reports, CAN/CAP, surveys, PSOE assessments, bow-tie, registers and their child rows — plus the Firestore audit_logs, psoe_assessments baselines and state SSP reference tree — across all tenants. Tenants, regulators, users and the PSOE question bank are preserved.

⚠️ This is irreversible!

Export Current Data

Download CSV backups before purging — the purge summary (per-table counts), a full dump of every table, or a single table.

Step 9

Delete Demo Tenants

Permanently delete demo operators (is_demo = true / is_beta_sandbox / CANCELLED status) from BOTH Supabase AND Firestore — every Postgres row for the tenant plus its Firestore doc including subcollections. Sita Air and Sourya Air are currently in CANCELLED state and can be deleted.

⚠️ This is irreversible!
