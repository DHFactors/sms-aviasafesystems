# Getting Started — Overview

**Step:** 01 — Getting Started  
**Guide:** AviaSAFE Tenant Onboarding Guide  
**Applies to:** AIRLINE_ADMIN, CAAN_SMD, USER  
**Prerequisites:** None

---

## 1. Overview

### 1.1 Purpose
Welcome to the AviaSAFE SMS Platform. This guide walks you through your first login, platform orientation, and what you can expect from the system. By the end of this step you will have an active account and a working understanding of the AviaSAFE dashboard.

### 1.2 Business Context
AviaSAFE is a multi-tenant Safety Management System (SMS) intelligence platform aligned with ICAO Annex 19, ICAO Doc 9859, and CAAN CAR-19. It provides:

- **Airlines (Service Providers):** Real-time visibility into SMS Maturity and Operational Risks via Voluntary Safety Reports (VSR), Mandatory Occurrence Reports (MOR), and Safety Culture Surveys.
- **CAAN (State):** Real-time State Safety Programme (SSP) intelligence by aggregating SMS Maturity and Operational Risks across all operators.

The platform has three core data sources (Survey, VSR, MOR) and two intelligence consumers (Airline SMS Dashboard, CAAN SSP Dashboard).

### 1.3 Expected Outcome
- A working AviaSAFE user account with appropriate role-based permissions
- Ability to log in and navigate the platform
- Understanding of the dashboard relevant to your role (AIRLINE_ADMIN / CAAN_SMD / USER)

## 2. Step-by-Step UI Guide

### 2.1 Navigation
1. Open your browser and navigate to **[https://sms.aviasafesystems.com](https://sms.aviasafesystems.com)** .
2. Click **"Login"** in the top-right corner of the landing page.

### 2.2 Input Matrix

| # | Field / Action | Type | Required | Constraints / Format | Notes |
|---|---------------|------|----------|---------------------|-------|
| 1 | Email Address | text | Yes | Valid email format (user@company.com) | Use the email provided by your system administrator |
| 2 | Password | password | Yes | Min 8 characters | Case-sensitive |
| 3 | "Sign In" button | action | — | — | Click to authenticate |

### 2.3 Execution
1. Enter your email address in the **Email** field.
2. Enter your password in the **Password** field.
3. Click **"Sign In"** .

### 2.4 Success Confirmation
Upon successful login you will be redirected to your role-based dashboard:
- **AIRLINE_ADMIN:** Tenant dashboard with SMS Maturity score, operational risk overview, recent reports, and survey status.
- **CAAN_SMD:** CAAN SSP Dashboard showing cross-tenant aggregated metrics.
- **USER:** Safety reporting interface with access to submit VSR / MOR reports.

If login fails, an error message will appear below the form (see Edge Cases).

## 3. Edge Cases

| Scenario | Expected Behaviour | Notes |
|----------|-------------------|-------|
| Incorrect email or password | Red error banner: "The password is invalid or the user does not have a password." | Use "Forgot Password?" link to reset |
| Account locked after multiple attempts | Error message: "Access to this account has been temporarily disabled." | Wait 15 minutes or contact your system administrator |
| No custom claims assigned | Login succeeds but dashboard may show limited data | Contact your system administrator to assign the correct role |
| Session expired | Redirect to login page with message: "Your session has expired. Please log in again." | Re-authenticate with your credentials |
| App Check challenge | reCAPTCHA v3 runs silently in the background — no user interaction required | If blocked, check network connectivity or contact support |

### Common Errors

| Error Message | Cause | Resolution |
|--------------|-------|------------|
| "The password is invalid or the user does not have a password." | Incorrect email or password | Verify credentials or use password reset |
| "Access to this account has been temporarily disabled." | Too many failed login attempts | Wait 15 minutes and try again |
| "Firebase App Check: reCAPTCHA error." | reCAPTCHA v3 failure (bot detection, network issue) | Retry; if persistent, add `?appcheck=false` to URL (development only) |
